## About Me

I'm Karthik Kaligotla, an inventor and engineer who works where networking, security, and machine learning meet. I hold two granted U.S. patents: one that catches phishing pages by checking whether a site that looks like your bank is actually run by your bank, and one that stops stolen data from slipping out of a network by rebuilding every outbound packet from scratch.

I like problems where the obvious defense is "detect the bad thing" and the better answer is to change the system so the bad thing cannot work. Check out my work below.

## What I Work On

- **Security invention:** phishing detection that pairs computer vision with network identity, and exfiltration prevention through packet regeneration.
- **Network engineering:** policy-based routing on Cisco IOS, packet capture with tcpdump, and packet crafting with Scapy.
- **Machine learning:** CNN brand classification and efficient text representations with Latent Semantic Analysis.
- **Full-stack web:** Next.js App Router, Server Actions, Prisma, and PostgreSQL.
